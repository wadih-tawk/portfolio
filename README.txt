WHAT THIS IS
My personal portfolio page. One HTML file and one CSS file. Everything is from what we did in Sessions 1 to 3.

FILES
index.html            the page
css/styles.css        all the styling
images/cli-image.png  the image in the hero section

HOW TO OPEN IT
Open index.html in a browser. Please keep the folders as they are, because
the CSS is linked as css/styles.css and the image as images/cli-image.png.

SECTIONS
Hero, About Me, Skills, Contact. Each one is a <section> with its own id so
the links in the nav can jump to it.

NOTES
- The contact form does not send anywhere. We have no backend yet, so I used
  action="#" and left the checking to the browser (required and type="email").
- The colors are the dark background, the cyan for headings and the bronze for
  links and the button.
- No inline styles and no leftover CSS rules.

Thanks for reading.
